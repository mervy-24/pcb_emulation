#pcb_emulation
This program emulates a process control block. It is essentially a linked
list of simple process information stored in memory.

##Usage
In the working directory:
make clean
./build/pcb

##What the demonstration shows:
- Insertion
- Rejection of duplicate insertion
- Removal
- Rejection of non-present elemental removal.

This was made for a university assignment many years ago as of this original
commit.
